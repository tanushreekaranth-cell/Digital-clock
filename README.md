# Digital-clock
A simple and responsive digital clock built using the knowlege of html and css and javascript.It displays the current hours, minutes and seconds in real time and updates automatically every second.

Digital Clock Web Project

A beginner-friendly digital clock website that displays the current time in a simple and attractive interface.


Overview

This project uses JavaScript to fetch the device's current time and update the display every second. CSS is used to create a clean, centered clock design.


🎨 Features

- ⏰ Real-time clock
- 🕐 Hours, minutes, and seconds
- 🔄 Automatic update every second
- 🎨 Attractive dark clock display
- 📱 Responsive layout
- 💻 Easy to understand and modify


🔧 Technologies

- HTML
- CSS
- JavaScript

Learning goal:
This project helps beginners understand how html, css and javascript work together to create an interactive web application.
